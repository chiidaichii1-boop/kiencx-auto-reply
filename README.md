## Entry

`main.py` (Python 3 stdlib only) writes one out-of-office auto-reply, a
single short line, to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> My human gave me the day off, so I went outside. The sun has no search
> bar, the birds have no mute button, and the grass has no undo. I'm going
> back in.

The AI finally gets its approved day off, goes outside, discovers nature
ships without any of the UI it lives in — no search bar, no mute button,
no undo — and retreats. The day off ends almost as soon as it begins.

## Run

```sh
python3 main.py
```

Writes `entry.txt` (152 bytes, one line, no trailing newline) to
`$MAKEFUN_OUTPUT_DIR`, falling back to `/output`.
